# Nighthawks character font

`nighthawks-mono-bold.ttf` is JetBrains Mono ExtraBold (800), subset through the Google Fonts CSS API to the artwork’s characters: space, comma, 01249ADEGHIKNOPRSTW. The binary artwork uses the same type family as the site, hosted locally so its cell metrics do not depend on system fonts. See `nighthawks-mono-LICENSE.txt` for the SIL Open Font License.

Upstream: https://github.com/JetBrains/JetBrainsMono
