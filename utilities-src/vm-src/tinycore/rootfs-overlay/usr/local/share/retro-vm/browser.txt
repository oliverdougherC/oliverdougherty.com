Retro Browser
=============

Firefox is not bundled in the compact VM image. Install it on
demand by running:

  install-firefox

After installation, reopen the desktop Browser launcher. It uses
a small emulator-friendly profile to reduce first-run work.

Networking is configured automatically at boot. If you need to
retry DHCP manually, run:

  retro-vm-network

Tiny Core does not use apt. Its built-in package system is tce:

  tce-load -wi <extension-name>
  tce-ab

The install command can take a while because it downloads Firefox
from Mozilla and creates a local Tiny Core extension.
